# Eval summary

Generated by `apps/api/scripts/eval_summary.py` from the run files in `evals/runs/`, the agent registry and the module reports; do not edit it by hand. It only reads results. Refresh it after a run:

```bash
cd apps/api
uv run python -m app.aiops.evalrun            # every agent, mock model (or: make eval AGENT=order_review)
uv run python -m app.aiops.evalrun --live     # the configured model (Claude or Gemini key in .env)
uv run python scripts/eval_summary.py
```

## What these numbers are

- 4 of the 12 committed runs used a real model (latest: run-2026-10-12T024105, gemini); the others are mock baselines.
- **The human rating sheets are still to be scored:** Control Tower narratives (7.1): accuracy 1-5 per narrative, gate mean >= 4 (`evals/control_tower/narrator/rating_sheet.md`: 0 of 30 rows scored); Documentation (7.3): completeness, accuracy, readability, format 1-5 per document, gate every mean >= 4 (`evals/documentation/rating_sheet.md`: 0 of 90 rows scored).
- All data is synthetic. Even a live run would show performance on synthetic cases written alongside the rules, not clinical performance.

Status words: **pending** = met its bar on the mock model (or not judged yet); **passed** = met its bar on a live model, or a pipeline eval; **failed** = below its threshold or a module gate failed. `task_success` is a strict per-case rate; thresholds (`eval_threshold`) are in each agent's YAML in `apps/api/config/agents/` with the reason in a comment (default 0.8).

## Where the eval sets live

- Hospital agents: `evals/<agent or module>/cases.jsonl` with a README of four sections (input resources, output schema, eval set and threshold, known failure modes); reports `report.md` / `report.json` next to them.
- Imaging agents (phases 2–4): `evals/datasets/*.json`, legacy per-task results in `evals/results/` (rewritten by every run of those agents).
- Runs: `evals/runs/run-<timestamp>.json`, one per runner invocation ([runs/README.md](runs/README.md)); the release and prompt gates read them.
- In the app: **AI Ops → Eval Center** (per-case results and the traces of failing cases) and **Compare**.
