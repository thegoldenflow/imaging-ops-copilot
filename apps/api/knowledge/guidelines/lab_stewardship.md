## repeat-tests
title: Repeating a test that already has a result
keywords: duplicate, repeat, test, laboratory, lab, imaging, x-ray, result, cbc, hemoglobin, creatinine, sodium, potassium, 72 hours
Repeating a laboratory test within a few days without a change in the clinical picture rarely changes management and adds cost and blood loss. Look at the existing result first. Daily routine blood work in a stable patient is a common example.

## serial-tests
title: When a repeat is expected
keywords: troponin, serial, inr, potassium, lactate, sepsis, monitoring, warfarin, repeat
Some repeats are planned: serial troponins to rule out a myocardial infarction, potassium after replacement, lactate in sepsis, the INR while warfarin is adjusted. The repeat should match the plan's interval.
